FIRST AID RAPID CONNECTIONS

First Aid rapid connections

Direct board correlations within the lecture scope: FOOSH → scaphoid → proximal AVN; carpal tunnel → median neuropathy → spared central palm; deep ulnar lesion → adductor pollicis weakness → Froment sign; proximal median lesion → loss of FDS/lateral FDP → benediction. These connections are intentionally sparse so the professor’s content remains primary.

Practical image recognition

30-second recall: SLTP / TTCH · Radius–scaphoid/lunate; TFCC–triquetrum · Snuffbox–scaphoid · Carpal tunnel median vs Guyon ulnar · Recurrent median = opposition · Deep ulnar = interossei/adductor pollicis · Lumbricals flex MCP and extend IP · PAD / DAB · Superficial ulnar vs deep radial palmar arch.
