Motor activation & sensory feedback

NMJ signaling

Motor AP → ACh vesicle release → nicotinic AChR → depolarization → T-tubules → SR Ca²⁺ → actin/myosin.
  • End-plate folds enlarge ACh receptor surface.
  • Acetylcholinesterase terminates cleft signal.
  • Botulinum cleaves SNAREs → no ACh release → flaccid paralysis.

Structure → disease and adaptation

Sarcolemmal support

Dystrophin–glycoprotein complex → laminin / ECM.
  • Defective linkage → sarcolemmal tearing → Ca²⁺ injury → necrosis.
  • Dystrophin → Duchenne; sarcoglycan → some limb-girdle dystrophies; LAMA2 → laminin-associated dystrophy.
  • Pseudohypertrophy = replacement fat/fibrosis, not functional growth.

Muscle plasticity

  • Satellite cells: fusion, myonuclei, regeneration and hypertrophy.
  • FAPs: fibro-adipogenic progenitors; fat/fibrosis in degeneration.
  • Atrophy: fiber shrinkage, loss of contractile material.
  • Sarcopenia: preferential age-related Type II atrophy and fewer Type II fibers.

FIRST AID RAPID CONNECTIONS

Only close lecture overlaps

  • Myasthenia gravis: AChR antibodies → fatigable ptosis/diplopia, often spared reflexes.
  • Lambert–Eaton: presynaptic calcium-channel antibodies → low release, hyporeflexia, proximal weakness.
  • Spindle Ia/II vs GTO Ib sensory fibers.
  • Type I oxidative/red vs Type II fast/glycolytic.
  • Hypertrophy: satellite-cell fusion; atrophy: myofibrillar degradation.
