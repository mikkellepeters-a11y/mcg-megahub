Posterior Forearm & Dorsum of Hand — Factoid

MSK-Skin · Week 16 · Lecture 1 · Manuel · Week 14 canonical compact factoid layout
Anchor set: Superficial extensors ↔ radial/deep radial; APL/EPB/EPL/EI ↔ PIN · SNB: APL + EPB / EPL · first dorsal web = superficial radial · PIN = motor · scaphoid retrograde flow → AVN · wrist drop · C5–6 Erb vs C8–T1 Klumpke.

Osteology & wrist landmarks

  • Lateral supracondylar ridge: BR + ECRL.
  • Lateral epicondyle: common extensor tendon.
  • Radius head ↔ capitulum; radial tuberosity ↔ biceps.
  • Radiocarpal: radius/disc ↔ scaphoid, lunate, triquetrum; ulna not directly in wrist joint.
  • Carpals 8 · metacarpals 5 · phalanges 14.

Superficial muscles: rapid map

  • BR: radial n.; elbow flexion strongest mid-prone; ends on distal radius.
  • ECRL: radial n.; base MC2; wrist extension + radial deviation.
  • ECRB: deep radial; base MC3; wrist extension + radial deviation.
  • ED: digits 2–5 MCP extension; common extensor tendon → expansions.
  • EDM: extension digit 5; ECU: MC5, extension + ulnar deviation.

Deep muscles: PIN signatures

  • Supinator: deep branch radial → turns radius to supinate.
  • APL: MC1; abduct thumb / extend CMC.
  • EPB: proximal thumb phalanx → extend MCP.
  • EPL: distal thumb phalanx → extend IP.
  • Extensor indicis: independent extension of index.
  • APL, EPB, EPL, EI: posterior interosseous n.

Radial nerve branching sequence

  • Posterior cord C5–T1 → radial groove + deep brachial artery.
  • In arm: triceps + posterior antebrachial cutaneous branch.
  • At proximal forearm: brachioradialis, ECRL; splits into superficial sensory / deep motor.
  • Deep branch crosses supinator → posterior interosseous n. (PIN).
  • PIN = motor; superficial radial = sensory.

Sensory testing — key split

  • 1st dorsal web space: superficial radial peripheral nerve.
  • Posterior forearm: posterior antebrachial cutaneous, given off in arm.
  • Lateral forearm: lateral antebrachial cutaneous ← musculocutaneous.
  • Medial forearm: medial antebrachial cutaneous ← medial cord.
  • Ulnar: dorsal medial hand; median: distal dorsal digital tips.
  • Dermatomes: C6 thumb · C7 middle · C8 little finger.

Anatomical snuffbox

  • Border A/lateral: APL + EPB; border P/medial: EPL.
  • Floor: scaphoid + trapezium.
  • Radial artery lies in floor; superficial radial branch crosses it.
  • FOOSH + snuffbox tenderness → consider scaphoid fracture.
  • Distal-to-proximal retrograde perfusion → proximal avascular necrosis risk.

Extensor hood & retinaculum

  • Extensor retinaculum: thick deep fascia prevents tendon bowstringing; 6 compartments in handout.
  • Synovial sheaths reduce friction; inflammation = tenosynovitis.
  • Dorsal expansion: ED + lumbricals/interossei.
  • Intrinsic activation gives MCP flexion with PIP/DIP extension.

Clinical — compare common injuries

  • Lateral epicondylitis: common extensor tendon overuse at lateral epicondyle. Slides emphasize tendinosis/non-inflammatory degeneration; handout describes periosteal inflammation.
  • Mallet finger: sudden forced DIP flexion → distal extensor insertion tear/avulsion → cannot actively extend DIP.
  • Radial groove lesion: wrist drop after humeral shaft trauma; sensory changes depend on lesion level.

Localization: lesion → deficit

  • High radial lesion: broad extension weakness ± triceps and dorsal sensation.
  • Deep radial/PIN: finger/thumb extension weakness; typically no cutaneous deficit.
  • Superficial radial: dorsal web-space numbness, motor intact.
  • Erb C5–C6: waiter’s tip (adducted/medially rotated, extended elbow, pronation).
  • Klumpke C8–T1: intrinsic hand weakness/claw hand.

Vessels & venous return

  • Brachial artery → radial + ulnar in cubital fossa.
  • Ulnar → common interosseous → anterior/posterior interosseous.
  • Posterior interosseous artery + PIN course together between extensor layers.
  • Radial artery → snuffbox → between 1st dorsal interosseous heads → deep palmar arch.
  • Dorsal venous network → cephalic (lateral) + basilic (medial).

Don’t mix these up

  • EPB vs EPL: MCP extension vs IP extension.
  • Superficial radial vs PIN: sensory vs motor.
  • C6 dermatome vs radial n.: root territory vs first web-space peripheral nerve.
  • Tennis elbow vs mallet finger: proximal common tendon overuse vs distal DIP extensor avulsion.
  • Upper vs lower plexus: C5–6 waiter’s tip vs C8–T1 claw.

First Aid rapid connections

  • FOOSH → scaphoid → retrograde flow → proximal segment ischemia.
  • Humeral shaft fracture → radial nerve groove → wrist drop.
  • Motor extensor deficit without sensory deficit → PIN compression near supinator.
  • Radial sensory loss alone → superficial radial branch localization.
